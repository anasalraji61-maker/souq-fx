# MATRIX

تطبيق شارتات وتحليل فني للمتداول الفردي بالفوركس والمعادن والسلع: مؤشرات، أدوات رسم، تنبيهات أسعار ومؤشرات،
تقويم اقتصادي، حاسبة حجم المركز، دفتر صفقات، وأكاديمية. **أداة تحليل وتعليم فقط** — لا ينفّذ
صفقات ولا يقدّم نصيحة استثمارية. لا عملات رقمية في قوائم الرموز.

> **في هذا المستودع تطبيقان — لا تخلط بينهما:**
>
> | | المجلد | البيانات | الحالة |
> |---|---|---|---|
> | **تطبيق MATRIX** (الذي يُرفع للمتجر) | `mobile/` + `backend/` | شموع حقيقية من المزوّد عبر الخادم، أو «غير متاح» صراحةً | هو موضوع كل ما في `docs/` |
> | **نموذج ويب تجريبي** (أُضيف 2026-10-01) | `src/` + `server.ts` بالجذر | **شموع مولَّدة عشوائياً** وتقويم ثابت مكتوب باليد | نموذج عرض، لا يتصل بـ`backend/` — تفصيله [أسفل الملف](#نموذج-الويب-التجريبي-بجذر-المستودع) |

## ما يراه المستخدم اليوم

أربعة تبويبات (`mobile/App.tsx`): **الرئيسية** (الشارت — `TerminalScreen`)، **الأدوات**
(`ToolsScreen`: التقارير، الدفتر، الحاسبة، الماسح، الاختبار الرجعي، تنبيهات السعر والمؤشرات، التقويم، التخطيطات،
المساعد التعليمي، ولوحة «إشارات ومجتمع»)، **الأكاديمية** (دروسها بالعربية فقط بكل لغات الواجهة، وعنوانها الفرعي بالإنجليزية
والكردية يقول ذلك — `coursesSub`، قرار أنس ١٢، `backend/academy_data.py`)، و**الحساب**. عند أول فتح تظهر جولة ترحيبية من خمس خطوات مرّة واحدة.

**مخفي بنسخة المتجر والكود باقٍ** (رايات `mobile/src/featureFlags.ts`، كلها `false`): لوحة الأخبار النصية
(`SHOW_NEWS_FEED` — قرار ٦: مصدراها القديمان ميّتان وغير مرخَّصين، والتقويم الاقتصادي يبقى)، و«المحلّلون» و«إجماع التواصل»
(`SHOW_UNLICENSED_SIGNAL_PANELS` — قرار ٥)، والباقات والعمولات والشبكة (`SHOW_REFERRAL_AND_PLANS` — قرار ١٠، تفصيله أدناه).
شاشة الرسائل الخاصة **حُذفت** (قرار ٩)، وميزة «البنوك» حُذفت (قرار ١). القرارات كلها في
[`docs/DECISIONS-ANAS.md`](docs/DECISIONS-ANAS.md).

الجرد المفصّل لكل ميزة وحالتها (منفَّذة / واجهة فقط / بيانات تجريبية / متّصلة بمزوّد) في
[`docs/FEATURE-INVENTORY.md`](docs/FEATURE-INVENTORY.md).

## التشغيل المحلي

### 1) الخادم — المنفذ **8110**
```bash
cd backend
python -m venv venv
# Windows: venv\Scripts\activate
pip install -r requirements.txt
python run_api.py
```
فحص: `http://127.0.0.1:8110/health`. (على ويندوز: `start-backend.bat` يفعل الشيء نفسه.)

`python main.py` يشغّل على **8100** (`MATRIX_PORT`) بإعادة تحميل تلقائي — والتطبيق **لا** يتصل
بهذا المنفذ، فاستعمل `run_api.py`.

مفاتيح المزوّدين (Twelve Data، OpenRouter، ElevenLabs) تُقرأ من متغيّرات البيئة بأسماء
`.env.example` بجذر المستودع (لا تُرفع `.env` أبداً). بدون مفتاح Twelve Data (أو حين يتعذّر المزوّد) **لا يرسل
الخادم شموعاً**: `candles: []` و`last` null مع `unavailable_reason: provider_unavailable` (`backend/main.py` `build_series`،
`8ff0a7c`)، والتطبيق يعرض مكان الشارت «تعذّر جلب شموع {الرمز} من مزوّد البيانات الآن». DXY لا يقدّمه المزوّد أصلاً
(`not_offered_by_provider`) ⇒ «DXY غير متاح من مزوّد البيانات» حتى بلا خادم. فلتجربة الشارت محلياً تحتاج مفتاحاً.
وإن لم يصل التطبيقُ الخادمَ أصلاً (بلا إنترنت أو الخادم متوقّف) فالشارت الرئيسي والإطارات والرباعي والتركيز بلا شموع أيضاً،
ومكانها «لا اتصال بخادم MATRIX» (`server_unreachable`، `11db392` و`5753fba` و`345b676`)، وشموع الظلّ لا تُرسم (`6005b59`).
وقبل أوّل ردّ تعرض الإطارات دوّاراً و«جارٍ تحميل شموع {الرمز} على فريم {الفريم}…» (`ce58542` و`df43700`) لا شموعاً.
**الاستثناء الوحيد الباقي** بشموع تجريبية موسومة «تجريبي» (`mobile/src/mock.ts`): شارت الدرس بالأكاديمية حين يفشل طلبه
(مقصود — للشرح لا للتداول)، وتحته سطر يقول إنها شموع تدريبية وإن ما يُرسم عليها لا يُحفظ (`22ff26c`، `aed77b9`). لم يُجرَّب أيّ من هذا على جهاز بعد.

### 2) التطبيق
```bash
cd mobile
npm install --legacy-peer-deps
npx expo start --lan
```
- `w` للويب، `a` لأندرويد، `i` لآيفون (محاكي أو Expo Go).
- عنوان الخادم **يُكتشف تلقائياً** (`mobile/src/apiHost.ts`): الويب يأخذ مضيف الصفحة نفسها + `:8110`، والهاتف
  في Expo Go يأخذ مضيف Metro (عنوان اللابتوب على الشبكة) + `:8110` — فلا يلزم تعديل شيء حين يتغيّر عنوان
  اللابتوب. لإجبار عنوان آخر: `EXPO_PUBLIC_API_URL=http://<العنوان>:8110 npx expo start`. التفاصيل في
  [`docs/RELEASE-MOBILE.md`](docs/RELEASE-MOBILE.md) §0 «عنوان الخادم».

## قبل أي بناء للمتجر

البناء المستقلّ (EAS) لا يملك مضيف Metro، فلا يعرف عنوان الخادم إلا من `EXPO_PUBLIC_API_URL` في بيئة EAS —
وبدونه يحاول `http://127.0.0.1:8110` ولا يصل. **لا خادم عام بـ`https` بعد**، فأي بناء اليوم لا يصل إلى الخادم
من هاتف مستخدم. الخطوات والقرار المطلوب في
[`docs/DEPLOYMENT.md`](docs/DEPLOYMENT.md)، ونصوص المتجر في
[`docs/STORE-LISTING.md`](docs/STORE-LISTING.md) و[`docs/STORE-PRIVACY.md`](docs/STORE-PRIVACY.md).

الباقات وخطة العمولات وشجرة الإحالة وخانة «رمز الدعوة» بالتسجيل **مخفية** بتبويب **الحساب** بقرار أنس ١٠
(`SHOW_REFERRAL_AND_PLANS = false` بـ`mobile/src/featureFlags.ts`، والكود باقٍ). قائمة الموانع كاملة وخطوات EAS في
[`docs/RELEASE-MOBILE.md`](docs/RELEASE-MOBILE.md).

## هيكل المشروع

```
backend/   FastAPI — شموع، تنبيهات، تقويم، دفتر، أكاديمية، مجتمع (ونقطة الأخبار باقية، واللوحة مخفية)
mobile/    Expo (React Native) — iPhone / Android / ويب
desktop/   غلاف سطح مكتب (يفتح سيرفر Expo المحلي — لا يعمل خارج جهاز التطوير بعد)
docs/      التوثيق وسجلّات الوكلاء
src/ server.ts  نموذج الويب التجريبي (بيانات مولَّدة — انظر آخر الملف)
```

## عزل مهم

تطبيق **MATRIX** (`mobile/` + `backend/` — تحليل فني) هو **ليس** روبوت التداول الموجود في مجلدات مثل
`MATRIX--ROBOT-` أو `MatrixRobot_*`. لا تدمج المنافذ أو الملفات أو المفاتيح بينهما.


## نموذج الويب التجريبي بجذر المستودع

أُضيف في 2026-10-01: React 19 + Vite + Express (`server.ts`) على المنفذ **3000**.

```bash
npm install
npm run dev
```

**ما فيه:** شارت Canvas بفريمات `1m 5m 15m 1h 4h 1D`، مؤشرات SMA وبولينجر وRSI وMACD والفوليوم، أدوات رسم، تخطيط
فردي ومزدوج ورباعي؛ وأدوات: حاسبة اللوت، دفتر صفقات، تقويم، ماسح، تنبيهات، اختبار استراتيجيات؛ وأكاديمية؛ وثلاث لغات (عربي/إنجليزي/كردي).

**ما ليس فيه — بصراحة:**
- **الأسعار والشموع ليست من السوق.** تولّدها `src/data/candleGenerator.ts` عشوائياً حول سعر أساس ثابت
  (`src/App.tsx`، `TerminalScreen.tsx`)، وتتحرّك بمؤقّت. لا اتصال بمزوّد بيانات ولا بـ`backend/`.
- **التقويم الاقتصادي ثابت** من `src/data/calendarData.ts` (أحداث مكتوبة باليد بتاريخ «اليوم») — ليس حيّاً.
- لذلك لا يُعرض هذا النموذج على متداول على أنه أسعار حقيقية (قرار أنس ١ و٢: لا رقم مُختلَق موسوماً كسعر حقيقي).

يحوي أيضاً لوحة تحكّم روبوت ونقاط `/api/bot/*` بـ`server.ts` — خارج تطبيق MATRIX كلياً، ولا يستعملها `mobile/` ولا `backend/`.
