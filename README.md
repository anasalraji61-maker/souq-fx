# MATRIX

منصة تحليل فني للفوركس (منافس مبسّط لـ TradingView) مع فريمات متعددة، مجتمع، ذكاء اصطناعي، ورسائل خاصة.

**معزول بالكامل** عن روبوت التداول Matrix/MT5 (الجسور ومنفذ 5555) وعن سوق العراق.  
منفذ API هذا التطبيق: **8100**.

## المنصات المستهدفة

| منصة | التقنية |
|------|---------|
| iPhone / Android | Expo (React Native) |
| Windows / Mac | Expo Web الآن + لاحقاً Electron/Tauri بنفس الواجهة |

## المميزات في هذه النسخة (MVP)

1. **طرفينال**: فريم كبير لـ **DXY** + 3 فريمات (صغير / وسط / كبير)
2. **دردشة جماعية**
3. **تصويت على صفقات**
4. **أخبار فوركس مؤثرة**
5. **مساعد AI** لتحليل وتوقعات ونسب نجاح تقديرية
6. **رسائل خاصة** (DM)
7. **أكاديمية** دورات لكل المدارس بمدرب AI

## التشغيل

### 1) الخادم
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
API: http://127.0.0.1:8100/health

### 2) التطبيق
```bash
cd mobile
npm install
npx expo start
```

- اضغط `w` للويب (ويندوز/ماك عبر المتصفح)
- اضغط `a` لأندرويد / `i` لآيفون (محاكي أو Expo Go)

على جهاز حقيقي: غيّر `extra.apiUrl` في `mobile/app.json` إلى IP جهازك.

## هيكل المشروع

```
MATRIX/   (حالياً المجلد: souq-fx — يُعاد تسميته عند إغلاق Cursor)
  backend/     FastAPI — شارتات، شات، تصويت، أخبار، AI، دورات
  mobile/      Expo — الطرفينال + الأكاديمية + الرسائل
```

## عزل مهم

هذا التطبيق اسمه **MATRIX** (تحليل فني)، وهو **ليس** روبوت التداول الموجود في مجلدات مثل `MATRIX--ROBOT-` أو `MatrixRobot_*`. لا تدمج المنافذ أو الملفات أو المفاتيح بينهما.
