# MATRIX - Forex Technical Analysis Terminal

تطبيق متقدم للتحليل الفني للعملات الأجنبية (Forex)، المعادن، المؤشرات، والعملات الرقمية.

## الميزات الرئيسية

- **الرئيسية (الشارت الفني)**:
  - شارت تفاعلي بتقنية HTML5 Canvas فائق السرعة وبمعدل 60 إطاراً في الثانية.
  - فريمات زمنية متعددة (1m, 5m, 15m, 1h, 4h, 1D).
  - مؤشرات فنية قياسية: المتوسطات المتحركة (SMA 20, 50, 200)، بولينجر باندز (Bollinger Bands)، مؤشر القوة النسبية (RSI 14)، الماكد (MACD)، وأعمدة الفوليوم (Volume).
  - أدوات رسم حرة ومستويات فيبوناتشي وخطوط الدعم والمقاومة.
  - تخطيط فردي وشارت مزدوج وشبكة رباعية (Quad Layout).
  - قائمة متابعة فورية مع فلاش لتغير الأسعار وسبريد مباشر.

- **الأدوات الفنية المتكاملة**:
  - **حاسبة حجم اللوت وإدارة المخاطر**: حساب دقيق للوت وفق وقف الخسارة ونسبة المخاطرة.
  - **دفتر الصفقات والإحصائيات**: تسجيل الصفقات ومتابعة نسبة النجاح (Win Rate) وصافي الأرباح ومعامل الربحية (Profit Factor).
  - **التقويم الاقتصادي الحي**: مفكرة الأحداث الاقتصادية العالمية المصنفة حسب درجة التأثير (قوي، متوسط، منخفض).
  - **الماسح الفني للأسواق**: رصد فوري لفرص التشبع البيعي والشرائي وتأكيد الاتجاه.
  - **تنبيهات الأسعار**: مراقبة المستويات المستهدفة مع تنبيه فوري واختبار صوتي.
  - **محاكي الاستراتيجيات (Backtester)**: اختبار نماذج واستراتيجيات التداول على البيانات السعرية ورسم منحنى نمو رأس المال (Equity Curve).

- **أكاديمية MATRIX للتداول**:
  - 7 مدارس تعليمية شاملة: أساسيات التداول، المدرسة الكلاسيكية، مدرسة وايكوف، ICT / SMC، مربع جان، موجات إليوت، ومدرسة SK.
  - قاعة محاضرات تفاعلية مع شرح صوتي، ومخططات بيانية توضيحية، واختبارات فهم فورية.

- **الحساب والإعدادات**:
  - دعم كامل لثلاث لغات: العربية (افتراضي مع اتجاه RTL)، الإنجليزية (US)، والكردية (Kurdish).
  - إخلاء المسؤولية القانونية والتنظيمية بأن المنصة أداة تحليل وتعليم فقط.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

يعمل السيرفر على المنفذ `3000` (المضيف `0.0.0.0`).
