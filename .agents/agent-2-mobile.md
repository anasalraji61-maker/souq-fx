# Agent 2 Mission: Cross-Platform Mobile App (Android & iOS)
**Target Area**: `/mobile/`

## Core Responsibilities:
1. Build and maintain the React Native / Expo application for Android (Google Play) and iOS (Apple App Store).
2. Optimize mobile touch gesture handling: pinch-to-zoom for candlestick charts, horizontal swipe for timeframe selection.
3. Integrate push notifications for price alerts and high-impact economic news.
4. Support full RTL layout for Arabic and Kurdish alongside English.
5. Strictly adhere to Expo SDK guidelines and zero-crypto compliance.
