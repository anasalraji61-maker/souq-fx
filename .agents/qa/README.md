# 🛡️ منظومة وكلاء الفحص والاختبار الذاتي (QA & Auto-Remediation Swarm)

تتألف هذه المنظومة من وكلاء متخصصين في فحص كل جزء ومحاكاة تجربة المستخدم العادي، مع آلية ذكية لإعادة توجيه الأخطاء تلقائياً إلى الوكيل المخطئ لإصلاحها:

---

## 🔍 وكلاء الفحص المتخصصون:

1. **QA Agent 1 (Chart & Mathematics Inspector):**
   - فحص دقة الشموع اليابانية والفوليوم وحسابات المتوسطات المتحركة وبولينجر باندز.
   - التأكد من عدم ظهور قيم غير معرفة (`NaN` أو `Infinity`).

2. **QA Agent 2 (Virtual User Persona Simulator):**
   - محاكاة متداول حقيقي يقوم بفتح الشارت، واختيار العملات، وحساب حجم اللوت، وتعيين التنبيهات، وقراءة دروس الأكاديمية.

3. **QA Agent 3 (Cross-Platform & Mobile Inspector):**
   - فحص توافق شاشات الهواتف (iOS و Android) في مجلد `mobile/` وحاسوب سطح المكتب في `desktop/`.
   - التأكد من دعم الاتجاه العربي (RTL) والأبعاد على الشاشات الصغيرة.

4. **QA Agent 4 (Auto-Remediation & Fault Dispatcher):**
   - العقل المدبر لإعادة الأوامر: عند حدوث أي خطأ برمجي، يقوم بتحديد الوكيل المسؤول، وكتابة تذكرة إصلاح فورية في ملف `ACTIVE_BUG_TICKET.md` لإلزام الوكيل المخطئ بتصحيحه فوراً قبل أي عملية دمج!
